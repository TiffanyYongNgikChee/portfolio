## Contributing

Thanks for taking an interest in improving this portfolio site. Small, focused contributions are welcome — especially accessibility fixes, copy edits, and image optimizations.

How to contribute
1. Fork the repository and create a new branch for your change (use a descriptive name, e.g. `fix/readme-links` or `chore/image-optimize`).
2. Make your changes and run the site locally to verify:

```
cd site
npm install
npm run dev
```

3. Commit with a clear message and open a pull request against `main`.

Reporting issues
- Open an issue and include: steps to reproduce, screenshots (if relevant), and the exact page or component name.

Coding style
- Keep changes small and focused.
- Use semantic HTML and Tailwind utility classes in `site/src`.

Questions
- Open an issue or reach out via the repository email/contact listed in the README.
